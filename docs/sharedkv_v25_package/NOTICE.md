# Provenance and limits

These are additive experimental files written for the user's `utazh/pans` v2.4 workflow. No original repository files, model parameters, datasets, or calibrator binaries are included. Runtime/replay code follows and depends on the user's published helper interfaces. Existing project and dependency notices/licenses remain applicable; this package does not relicense the repository or assign a blanket license to its dependencies.

All suggested effects remain hypotheses until verified on the user's server. `diagnostic_only`, source/model identity guards, query split provenance, and cold-cache preconditions are deliberately retained.
