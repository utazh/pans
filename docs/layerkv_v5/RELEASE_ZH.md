# LayerKV v5：A100 与多模型实验代码快照

发布日期：2026-10-07。来源为服务器 qyd/pans 的 a100、a100-q14、a100-q32 工作目录，三者当前代码提交均为 2ac246aa7c03e5a5ff66af527ba95ebd182b865f。基于公开 v4，保留内部 v29/v29m 名称。新提交按快照发布，原 15 次本地提交列表见 code_manifest.json。

## 这轮做了什么

1. 将模型路径、query/KV 头编号、计时 GPU、CPU 亲和性、NUMA 核与磁盘监控改为环境变量配置，支持 Qwen2.5-7B/14B/32B。
2. 新增 v29m_pipeline.py：teacher fit/val 采集、按层数与选择几何生成共享图、R4 离线训练、冻结 R0 导出、S1/S2/S3 三档回退、开发筛选及完整测试。保留 200 步初始研究与 800 步扩展。
3. 新增 A100 主计时和四系统同块对照：I、共享候选、ContiguousKV 适配路径、IMPRESS 适配路径；保存失败、干扰标记和重试记录。
4. 增加 MiniCache-Prefix 构建/质量实验、跨层 KV 相似性分析，以及部署、数据准备和运行辅助脚本。这些辅助脚本原位于 xfer，发布于 server_a100/xfer。
5. 共享 attention 核心继续沿用旧版本；当前 query/生成 token 的 KV 仍逐层独立。大模型需要各自校准的 reader，不能直接把 7B 权重当成通用读取器。

下表为 800 步实验、25% 预算、开发集选定配置的完整测试准确率。S1/S2/S3 是各模型共享程度，不是跨模型相同的来源数。I 表示开发筛选回退无共享。

| 14B | SUBJ | S3 | 50.85% | 50.85% |
| 14B | TREC | I | 82.40% | 82.40% |
| 14B | RTE | S1 | 91.34% | 92.06% |
| 32B | SST-2 | S3 | 94.27% | 94.38% |

所有候选结果见 results/quality_summary.json，包括未选中的退化候选。例如 14B/TREC 的 S1/S2 明显低于 I，32B/SUBJ 的共享候选也下降。以上是开发集点估计规则选择，不是统计非劣认证。没有将选中为 I 的格子称为共享无损。

7B 新训练 TREC/25% 200 步研究为 I 68.0%、S1 73.8%、S2 72.6%、S3 79.0%，与迁移的旧 3090 reader 分开保留；不能把这个新 checkpoint 的准确率配上旧 reader 的延迟。

## 计时范围

- a100_timing_q7：144 个有效块，四数据集×四预算冷测，并含 25%/50% 普通缓存。
- a100_timing_q14、a100_timing_q32：各 24 个有效块，对应 25% 预算四任务冷测。
- a100_sys_q7/q14/q32：各 48 个有效块，25% 预算四任务的冷/普通缓存四系统对照。
- 每块 16 条请求，每格 6 块；不是完整评估集计时。有效块关联的 10464 条冷记录 status 均为 completed；本次仅核对已保存记录，没有重新认证硬件冷态。
- 四系统计时在开发选择 I 时，仍用 S3/G16 作为共享参考臂。该臂的速度不能与 I 的准确率拼成一个“选中方法”结果。
- protocols 保留无效/中断尝试；results/timing_blocks.json 只使用 all_ok 且无 flag 的块，对相同 cell/condition/block 取最后有效记录，并附逐请求文件 SHA256。正式报告应同时考察配对块、运行顺序和质量。
- CKV/IMPRESS、MiniCache 是本项目适配路径，不声称已完成所有官方系统的等资源复现。MiniCache 的解析存储估计不等于其重建缓存文件的物理占用。

## 发布验证和边界

本次只整理与验证发布副本，没有重新训练或运行 GPU 实验。CPU 回归 **680 passed、33 skipped、87 subtests passed**；55 个 Python 文件语法检查和 31 个 shell 文件 bash -n 检查通过。40 个模型/候选质量汇总与原始逐请求预测重算一致。

首次 CPU 运行有两项因系统 /tmp 满而失败；设置独立 TMPDIR 后全套通过，首次和复跑日志均保留。没有为通过测试修改算法。

代码、环境模板、轻量结果、计划与审计记录进入 Git。模型、reader checkpoint、teacher/KV cache、原始任务正文、生成排序大文件、依赖安装包及旧迁移压缩包留在服务器。源工作目录不改动。

server_a100 是原服务器布局快照，不是零配置安装包。它包含历史补丁、恢复及排队脚本，部分会修改工作目录或启动 GPU 作业；先检查路径和空闲资源，再有选择地使用。最终运行入口优先采用 scripts 中当前版本，server_a100/xfer 中的同名文件可能是历史传输稿。

使用前准备模型专属 prefix store、Pcache、K4 索引、数据、reader 和软链接。source env_q14.sh/env_q32.sh 后需要让 PANS_ROOT 指向对应工作目录；计时 GPU/CPU 设置在 env_timing.sh。不能把这些机器专属默认值直接用于另一台服务器。

原始代码提交及文件哈希见 code_manifest.json，复制结果来源见 copied_artifacts_manifest.json，检查记录在 validation。当前快照哈希不保证每次历史实验的执行源码均完全相同。
